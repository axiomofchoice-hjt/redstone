# 放置 / 交互模式与波形图

「放置」（电脑端）和「交互」（手机端）用来拨输入，同时把端口的最近 32 个 tick 画成波形。

## 放置 / 交互模式

点输入元件可以切换它的 0 / 1。

- 电脑端：检查器里的模式按钮上写的就是当前模式，点一下切换。「放置」模式下点输入元件拨 0 / 1，放元件只填空格、不覆盖已有元件；「覆盖」模式下放元件直接替换已有元件，点输入元件不会拨开关。检查器里一直有波形，点行首的字母也能拨 0 / 1。
- 手机端：进交互模式时，底部元件栏（元件、方向键、删除）整个换成和电脑端检查器一样的波形图；每个端口一行，点行首的字母直接拨 0 / 1，行尾显示当前取值。再点一次「交互」还原成上一次选的元件。手机端没有放置 / 覆盖的模式切换，放置仍然会覆盖。

两端的波形用的是同一份采样。

## 波形怎么画

- 每个声明的端口一行，横轴是最近 32 个 tick（4 tick/s 下 8 秒），右端是「现在」。
- 高电平画在上沿，并用淡红块标出来。
- 关卡声明的端口全列出来：还没放到地图上的端口也占一行，输出一直按 0 画，输入显示玩家设的 0 / 1。
- 开局还没攒满 8 秒时左边按 0 补满，所以一上来就是一整条 0 线。

## 采样规则

- 输入元件删掉后玩家设的值还留着，波形继续按那个电平画。
- 改元件会重建仿真，但时间轴接着走，已经画出来的波形不会被打断。
- 改完电路或拨输入，输出会立刻按新电路刷新，当前这一格的采样也直接覆盖成新值，不用等下一个 tick，之后时间往前走也不会退回旧电平。

回放时的波形（多几条参考解输出、检查区间铺底色、成对检查的对比区间）见[测试与回放](testing.md)。
