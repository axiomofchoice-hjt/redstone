# 放置 / 交互模式与波形图

电脑端的「放置」模式和手机端的「交互」工具用来拨输入；平时波形图把每个端口的最近 32 个 tick 画出来。

## 放置 / 交互模式

点输入元件可以切换它的 0 / 1。

- 电脑端：检查器里的模式按钮上写的就是当前模式，点一下切换。「放置」模式下点输入元件拨 0 / 1，放元件只填空格、不覆盖已有元件；「覆盖」模式下放元件直接替换已有元件，点输入元件不会拨开关。检查器里一直有波形，点行首的字母也能拨 0 / 1。
- 手机端：进交互模式时，底部元件栏（元件、方向键、删除）整个换成和电脑端检查器一样的波形图；每个端口一行，点行首的字母直接拨 0 / 1，行尾显示当前取值。再点一次「交互」还原成上一次选的元件。手机端没有放置 / 覆盖的模式切换，放置仍然会覆盖。

两端的波形用的是同一份采样。

## 波形怎么画

- 每个声明的端口一行，横轴是最近 32 个 tick（4 tick/s 下 8 秒），右端是「现在」。
- 高电平画在上沿，并用淡红块标出来。
- 关卡声明的端口全列出来：还没放到地图上的端口也占一行，输出一直按 0 画，输入显示玩家设的 0 / 1。
- 开局还没攒满 8 秒时左边按 0 补满，所以一上来就是一整条 0 线。

## 采样规则

- 输入元件删掉后玩家设的值还留着，波形继续按那个电平画。
- 改元件会重建仿真，但时间轴接着走，已经画出来的波形不会被打断。
- 改完电路或拨输入，输出会立刻按新电路刷新，当前这一格的采样也直接覆盖成新值，不用等下一个 tick，之后时间往前走也不会退回旧电平。
- 地图、波形最右一格和行尾显示的是实时输出：中继器、反相器刚跑完这一拍就显示新电平。测试检查读的是每个 tick 开头的采样值（`output()`），和显示用的实时输出是两份，细节见[时间模型与仿真](simulation.md)。

回放时横轴会换成整组测试（0 到测试结束）：进回放先整组跑一遍，整条波形和检查区间一开始就全部画满（有参考解时连参考解输出一起），橙色竖线只是当前 tick 的播放头，单步只移动竖线。播放头以当前这一格的右边界为中线、两边各压一半（采样格是 `[tick, tick + 1)`），波形在那儿从 0 跳到 1 或反过来时，跳变那条竖线整个被红线盖住；细节见[测试与回放](testing.md)。

回放时还能直接点波形跳转：整块面板都能点，只要横坐标落在图上（两行之间的空隙也算）；横轴按整组测试的 tick 均分，点到第几格就停到第几刻，地图和输入 / 输出当前值一起走到那里（有参考解时还有参考解当前值），点完自动暂停。电脑端和手机端都能点；编辑 / 交互时那 32 tick 的窗口不是进度条，点了不会跳。
