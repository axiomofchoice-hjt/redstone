# 测试与回放

怎么跑测试、结果怎么显示，以及未通过时那套回放。

## 运行测试

手机端在工具栏、电脑端在顶栏右上角的「测试」按钮（长按提示「运行测试」）。第 0 tick 从编辑器里当前的电路状态开始跑，不会动到编辑器那份，细节见[关卡数据格式](levels.md)。

## 结果状态

手机端工具栏、电脑端顶栏「测试」右边都显示「测试结果：」加一个图标：

- 没运行：三个点（点落在基线上，靠下不居中）
- 全部通过：勾
- 未通过：叉

两端的按钮都是只有未通过时能点，另外两种状态是禁用的。

## 回放

点未通过的「测试结果：×」进入回放：电路从冷启动重跑第一组没通过的测试（输入一开始全是 0，之后由测试事件拨），仿真暂停，地图和波形跟着「继续」/「下一刻」一起往前走，跑完这组测试就停下，最后一刻的单步按钮不可点。手机端底部元件栏换成波形图，电脑端检查器里的波形直接多画参考解和检查区间。参考解那一侧会先恢复参考解保存的通电状态（tick 和输入仍从 0 开始），这样触发器的相位和参考解一致。

- 回放时点输入字母不会再切换电平，地图也不能改；电脑端的元件、放置 / 覆盖、删除和方向按钮都变灰。
- 波形和平时一样右端是「现在」，上半是玩家自己的输入 / 输出，下半多几条「参考解」的输出（字母用虚线框，不重复画输入），测试的检查区间按期望值铺底色（期望 1 是浅绿、期望 0 是浅灰）。
- 「上一刻」（一条竖线加一个朝左的三角形）在暂停时才能点，从冷启动重跑到前一个 tick，地图和波形一起退。手机端它替掉工具栏里的「交互」，电脑端出现在暂停左边。
- 再点一次结果按钮就退出回放，电路、输入和暂停 / 运行状态都原样还回去。
- 按「测试」会先退出回放再重新测。

组件实现见 `src/ui/Waveform.tsx` 和 `src/ui/trace.ts`。
