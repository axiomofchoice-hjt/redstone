# 测试与回放

怎么跑测试、结果怎么显示，以及未通过时那套回放。

## 运行测试

手机端在工具栏、电脑端在顶栏右上角的「测试」按钮（长按提示「运行测试」）。每次点都先把现场这块电路和它当前的仿真状态 fork 一份快照，再拿快照把这一关的测试全跑一遍：编辑器之后接着跑、接着改都影响不到这次结果，也不会动到编辑器那份。改电路、拨输入都不会把上一次的结果清掉——「测试结果」一直是上次跑出来的勾/叉，点它还能看那一次的回放；只有再点一次「测试」才会重算并替换，换关时也会清掉。细节见[关卡数据格式](levels.md)。

## 结果状态

手机端工具栏、电脑端顶栏「测试」右边都显示「测试结果：」加一个图标：

- 没运行：三个点（点落在基线上，靠下不居中）
- 全部通过：勾
- 未通过：叉

两端的按钮都是只有未通过时能点，另外两种状态是禁用的。

## 回放

点未通过的「测试结果：×」进入回放：按那次测试的快照重跑第一组没通过的测试（电路、输入和内部状态都保持点「测试」那一刻的样子，横轴上的 tick 从 0 数，之后由测试事件拨输入），仿真暂停，地图和红色播放头跟着「继续」/「下一刻」一起往前走，跑完这组测试就停下，最后一刻的单步按钮不可点。手机端底部元件栏换成波形图，电脑端检查器里的波形直接多画参考解和检查区间。回放的横轴铺整组测试（0 到测试结束），不是最近 32 个 tick。参考解那一侧会先恢复参考解保存的通电状态（tick 和输入仍从 0 开始），这样触发器的相位和参考解一致。

- 回放时点输入字母不会再切换电平，地图也不能改；电脑端的元件、放置 / 覆盖、删除和方向按钮都变灰。
- 回放时横轴不是最近 32 个 tick，而是整组测试：左端 0、右端测试结束。进回放时先把这组测试从测试快照整个跑一遍，整条输入 / 输出波形和参考解输出一次画满，橙色竖线只当播放头，「继续」/「下一刻」/「上一刻」只移动竖线、波形不动，不用等播放到才长出来。播放头以当前这一格（采样格 `[tick, tick + 1)`）的右边界为中线、两边各压一半：波形在那儿跳变时正好把那条竖线整个盖住，线宽和位置都按设备像素取整，两端也不会被裁掉。
- 回放波形可以直接点：整块面板都能点（两行之间的空隙、横轴刻度和参考解那几行也算），只要横坐标落在图上；点到第几格就把进度跳到第几刻（这一格画的就是那一 tick 的采样，红线停在这一格的右边界），地图、输入 / 输出和参考解的当前值一起走到那里，点完自动暂停。行首字母、行尾数字和面板留白不算。电脑端检查器和手机端回放面板都能点，手指点也一样；编辑 / 交互时那 32 tick 的窗口不是一个进度条，点了不会跳。
- 上半是玩家自己的输入 / 输出，下半多几条「参考解」的输出（字母用虚线框，不重复画输入）。测试的检查区间按期望值铺底色（期望 1 是浅绿、期望 0 是浅灰），和波形一起在进回放时全部画出来。
- 成对检查（`pairs`，时钟、T 触发器这类只看两个时刻是翻转还是保持的测试）没有固定期望电平：两个时刻之间铺一段淡蓝底，两个时刻各画一条深色竖条，相邻的对比区间会并成一段。
- 「上一刻」（一条竖线加一个朝左的三角形）在暂停时才能点，从冷启动重跑到前一个 tick，地图和红线一起退一格，波形不动。手机端它替掉工具栏里的「交互」，电脑端出现在暂停左边。
- 回放放的是**那一次测试的快照**：改完电路再点开结果，地图会切回点「测试」那一刻的电路和状态（波形和检查区间也按它算），退出回放再把当前这块电路还回来。
- 再点一次结果按钮就退出回放，电路、输入和暂停 / 运行状态都原样还回去。
- 按「测试」会先退出回放再重新测。

组件实现见 `src/ui/Waveform.tsx` 和 `src/ui/trace.ts`。
