# 界面与操作

两套布局、放置与删除、平移缩放、快捷键，以及菜单里那几个功能。

## 两套布局

宽度 ≥ 1024px 时用电脑端布局：左侧检查器（元件、朝向、放置 / 覆盖模式、删除、缩放滑轨、波形），右侧画布。窄于这个宽度用手机端布局：单列，地图占中间，底部是元件栏，工具栏在地图下方。

两套布局共用同一份游戏状态，拖窗口跨过断点不会重置正在搭的电路。

## 放置与删除

手机端底部是元件栏，选中后点击地图放置，可以连续放置；右键点格子直接删掉这一格，元件栏选中的元件不变，也可以先切到「删除」（垃圾桶图标）再点。

电脑端在地图上按住左键拖动可以一路连续放置，按住右键拖动可以一路连续删除；手机端右键 / 长按仍然只删一格。

电脑端默认是放置模式；检查器里的模式按钮上写的就是当前模式，点一下在两种模式之间切换：

- 放置：放元件只填空格，不会盖掉已有元件；点输入元件可以拨 0 / 1，拖动经过输入元件不会一路反复拨。
- 覆盖：放元件直接替换格子上的元件（锁定的端口除外），点输入元件也不会拨开关。

手机端没有模式切换，仍然是选中元件后放置 / 覆盖；「交互」工具只用来拨输入。

## 平移与缩放

地图比屏幕大时：手机端直接拖动，电脑端按 WASD / 方向键平移（键指「想看哪边」，按住不放会一直平移，每秒 8 格）。

电脑端拖左侧检查器的「缩放」滑轨缩放（0.5x–3x），以视口中心为锚点；100% 时一格固定 54px，所有关卡一样大，7×7、10×10 都能一屏放下；20×20 的第十九关在 1440×900 的窗口里 100% 会超出一屏，滑到 0.7x 以下（窗口越矮要越小）或者按 WASD / 方向键平移才能看全。

手机端用双指或鼠标滚轮缩放（0.5x–3x），滚轮以鼠标位置为中心。

电脑端和手机端都能按键盘 `+` / `-` 缩放（主键区不按 Shift 的 `=` 也能放大），以视口中心为锚点，在 50% / 67% / 75% / 80% / 90% / 100% / 110% / 125% / 150% / 175% / 200% / 250% / 300% 这些档位里跳到相邻的一档：滑轨或捏合停在 83% 这种非档位时，`+` 跳到 90%、`-` 跳到 80%；按住不放会连续跳，到头停在 50% / 300%。Ctrl / Cmd + `+` / `-` 留给浏览器缩放，不会动地图。

## 朝向

用方向按钮选择朝向，图标会跟着转；电脑端还可以滚动鼠标滚轮转 90°（往前滚逆时针、往后滚顺时针）。

## 快捷键

- 电脑端数字键 1～5 选基础元件，6～9 按元件栏顺序选输入 / 输出；超过 9 个的端口用鼠标点。
- `+` / `-`（或 `=` / `_`）缩放地图，电脑端和手机端都认。
- 手机端的 W / A / S / D 仍然用来换朝向。

## 首页与自由模式

首页有「进入游戏」和「查看教程」两个按钮：前者直接打开选关界面，后者打开占满全屏的图文教程（和游戏内菜单里的「查看教程」是同一个页面）。窄屏时首页在说明文字和按钮之间还会显示那张装饰电路图。

选关页顶栏是「首页」和「自由模式」两个按钮，自由模式不再作为卡片排在关卡列表里。点「自由模式」进一张 20×20 的空白沙盒：元件全开，没有输入 / 输出元件，也没有测试和目标，所以「测试」、测试结果和波形这些入口都会收起来，标题也不显示关卡号；电脑端的放置 / 覆盖模式还在，自由模式也用它决定放元件会不会覆盖。

## 菜单

参考答案、导出地图和查看教程收在菜单里；返回选关单独放在菜单键右边，是一个只有退出图标的返回按钮。

- 电脑端：顶栏菜单键，暂停 / 下一刻 / 测试仍然摆在顶栏外面。
- 手机端：整屏菜单，打开期间仿真暂停，地图和底部栏隐藏；「继续游戏」收起菜单。「查看教程」排在「返回选关界面」上面。

「参考答案」把这一关的参考解盖到地图上，并恢复到保存时的电路状态（`tick`、输入、通电状态一起恢复，会冲掉当前搭的电路）。参考解写在关卡数据的 `solution` 里，没有解的关卡按钮是灰的、点不了；字段格式见[关卡数据格式](levels.md)。

「导出地图」把当前地图和导出时的电路状态下成 `level-XX-map.json`，格式见[关卡数据格式](levels.md)。

「查看教程」打开占满全屏的图文教程，一共六页：简介、导线与交叉导线、充能器与中继器、反相器、输入与输出、断路器与 D 锁存器。第一页是简介，说明这是一款简化的 Minecraft 红石电路模拟器，仅由 5 种基本元件和输入、输出两种关卡元件构成，电路整体按 tick 同步运行，并排出这 7 种元件的图；第二页标题下先排导线、交叉导线两张元件图（和第一页的全家福同一套样式），再用四张图讲这两种导线（亮灭状态由仿真引擎算出），四张图放在正文右边、窄屏时落到正文下面，第三页介绍充能器和中继器，电脑端左栏是元件卡和正文、右栏是两组状态图，窄屏时图落到正文下面；两组的图都用同一张 4×3 网格（中间一行是输入 A、导线、元件、导线），分两组：充能器两张看方向（朝右点亮右边导线，朝左时充能器和右边导线都不亮），中继器两张都朝右看 1 tick 延迟（刚拨上时右边导线不亮，晚 1 tick 才亮），颜色同样由仿真算出，第四页介绍反相器，标题下同样放一张反相器元件卡，电脑端左栏是元件卡和正文、右栏是两张 4×3 状态图，图上方的小标题是「反相器」，窄屏时图落到正文下面；两张图都是中间一行输入 A、充能器（朝右）、反相器、导线，左边 A 未激活、反相器输出 1、右边导线亮，右边 A 激活、过 1 tick 充能器把反相器顶灭、导线也跟着灭，颜色同样由仿真算出，第五页介绍输入和输出，标题下排输入、输出两张元件卡，正文说明输入 / 输出是关卡特有的元件，游戏指定动态的输入信号并观察输出信号来判断测试是否通过，电脑端右栏是两张 3×4 状态图（中间两格左边放输入 A、B，右边放输出 Y、Z），窄屏时图落到正文下面；第六页介绍断路器和 D 锁存器，正文说明断路器是由充能器和中继器组成的复合结构、充能器对着中继器的侧面摆放、充能器输出 1 时中继器被抑制、否则输出背后的信号，D 锁存器是由两个中继器组成的复合结构、中继器 X 对着中继器 D 的侧面摆放、X 输出 1 时 D 维持输出不变、否则输出背后的信号，两者都有 1 tick 延迟，电脑端右栏是两组 3×4 状态图：上面断路器，左图 A = 1、B = 0 时中继器正常输出 1，右图 A = 1、B = 1 时充能器把中继器顶灭、输出 0；下面 D 锁存器，左图 A = 0、B = 1 时中继器被锁住并保持 0，右图 A = 1、B = 1 时下面的中继器仍保持 0、不跟着 A 变，窄屏时图落到正文下面，页末小字写「断路器参考 Minecraft 红石比较器，D 锁存器参考 Minecraft 红石中继器的锁存功能。」内容仍和[元件与信号规则](rules.md)一致。点底部「上一页」/「下一页」或按键盘 ← / → 翻页，点中间的小圆点直接跳到那一页；右上角 × 或 Esc 收起（从首页打开时回首页，从菜单打开时回地图）。

## 关卡信息

电脑端顶栏菜单键左边的 ⓘ 就地展开本关目标，点外面、再点一次 ⓘ 或按 Esc 收起；手机端顶栏同样位置的 ⓘ 打开只显示目标的页面，再点一次 ⓘ 或按「返回地图」收起。

## 暂停与单步

手机端在地图下方、电脑端在右上角（菜单键左边）的按钮可以暂停 / 继续、手动推进一个 tick。回放时也可以直接点波形跳转：面板里只要横坐标落在图上，点到第几格就停到第几刻，点完自动暂停，电脑端和手机端都能点。「测试」按钮和结果状态见[测试与回放](testing.md)。

## 换关

电脑端顶栏最右边的返回图标直接回关卡列表；手机端在菜单里选「返回选关界面」。
