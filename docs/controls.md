# 界面与操作

两套布局、放置与删除、平移缩放、快捷键，以及菜单里那几个功能。

## 两套布局

宽度 ≥ 1024px 时用电脑端布局：左侧检查器（元件、朝向、放置 / 覆盖模式、删除、缩放滑轨、波形），右侧画布。窄于这个宽度用手机端布局：单列，地图占中间，底部是元件栏，工具栏在地图下方。

两套布局共用同一份游戏状态，拖窗口跨过断点不会重置正在搭的电路。

## 放置与删除

手机端底部是元件栏，选中后点击地图放置，可以连续放置；右键点格子直接删掉这一格，元件栏选中的元件不变，也可以先切到「删除」（垃圾桶图标）再点。

电脑端在地图上按住左键拖动可以一路连续放置，按住右键拖动可以一路连续删除；手机端右键 / 长按仍然只删一格。

电脑端默认是放置模式；检查器里的模式按钮上写的就是当前模式，点一下在两种模式之间切换：

- 放置：放元件只填空格，不会盖掉已有元件；点输入元件可以拨 0 / 1，拖动经过输入元件不会一路反复拨。
- 覆盖：放元件直接替换格子上的元件（锁定的端口除外），点输入元件也不会拨开关。

手机端没有模式切换，仍然是选中元件后放置 / 覆盖；「交互」工具只用来拨输入。

## 平移与缩放

地图比屏幕大时：手机端直接拖动，电脑端按 WASD / 方向键平移（键指「想看哪边」，按住不放会一直平移，每秒 8 格）。

电脑端拖左侧检查器的「缩放」滑轨缩放（0.5x–3x），以视口中心为锚点；100% 时一格固定 54px，所有关卡一样大，7×7、10×10 都能一屏放下；20×20 的第十九关在 1440×900 的窗口里 100% 会超出一屏，滑到 0.7x 以下（窗口越矮要越小）或者按 WASD / 方向键平移才能看全。

手机端用双指或鼠标滚轮缩放（0.5x–3x），滚轮以鼠标位置为中心。

## 朝向

用方向按钮选择朝向，图标会跟着转；电脑端还可以滚动鼠标滚轮转 90°（往前滚逆时针、往后滚顺时针）。

## 快捷键

- 电脑端数字键 1～5 选基础元件，6～9 按元件栏顺序选输入 / 输出；超过 9 个的端口用鼠标点。
- 手机端的 W / A / S / D 仍然用来换朝向。

## 首页与自由模式

首页只有「进入游戏」一个入口，直接打开选关界面。窄屏时首页在说明文字和按钮之间还会显示那张装饰电路图。

选关页顶栏是「首页」和「自由模式」两个按钮，自由模式不再作为卡片排在关卡列表里。点「自由模式」进一张 20×20 的空白沙盒：元件全开，没有输入 / 输出元件，也没有测试和目标，所以「测试」、测试结果和波形这些入口都会收起来，标题也不显示关卡号；电脑端的放置 / 覆盖模式还在，自由模式也用它决定放元件会不会覆盖。

## 菜单

参考答案、导出地图、返回选关都收在菜单里。

- 电脑端：顶栏菜单键，暂停 / 下一刻 / 测试仍然摆在顶栏外面。
- 手机端：整屏菜单，打开期间仿真暂停，地图和底部栏隐藏；「继续游戏」收起菜单。

「参考答案」把这一关的参考解盖到地图上，并恢复到保存时的电路状态（`tick`、输入、通电状态一起恢复，会冲掉当前搭的电路）。参考解写在关卡数据的 `solution` 里，没有解的关卡按钮是灰的、点不了；字段格式见[关卡数据格式](levels.md)。

「导出地图」把当前地图和导出时的电路状态下成 `level-XX-map.json`，格式见[关卡数据格式](levels.md)。

## 关卡信息

电脑端顶栏菜单键左边的 ⓘ 就地展开本关目标，点外面、再点一次 ⓘ 或按 Esc 收起；手机端顶栏同样位置的 ⓘ 打开只显示目标的页面，再点一次 ⓘ 或按「返回地图」收起。

## 暂停与单步

手机端在地图下方、电脑端在右上角（菜单键左边）的按钮可以暂停 / 继续、手动推进一个 tick。「测试」按钮和结果状态见[测试与回放](testing.md)。

## 换关

电脑端顶栏最右边菜单里的「返回选关」直接回关卡列表；手机端在菜单里选「返回选关界面」。
