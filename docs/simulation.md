# 时间模型与仿真

逻辑以 tick 为单位推进，编辑时每秒 4 tick；测试读取的是每个 tick 的输出采样值。

## 元件延迟

无延迟元件（导线、交叉导线、充能器）在同一 tick 内传播到稳定，中继器和非门延迟 1 tick 生效。

中继器被侧面锁住的那个 tick 不采样，输出保持不变；被侧面充能器断路时按 0 采样，同样延迟 1 tick 生效。规则细节见[元件与信号规则](rules.md)。

## 增量更新

仿真走增量更新：每个导线网络记着「有几个外部元件在驱动它」，只有数量 0↔1 翻转时才通知贴在网络边上的格子；充能器变化只沿它自己的方向往外传，网络翻转也只碰相关的格子。

每 tick 开头仍会扫一遍所有格子，逐个算非门和中继器这一拍的输出；省掉的是以前那种每次变化都全图迭代到稳定的求解。

原来的全量算法（全图迭代到稳定）保留在 `snapshotFull()` 里，只给测试当对照，测试会逐 tick 比对两套结果。

## 绘制

绘制同理：画布只遍历视口内的格子，通电状态也是按格取的（`powerAt()`），不会为了画几格把整张图算一遍。
