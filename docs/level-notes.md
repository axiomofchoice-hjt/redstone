# 各关设计说明

单关的特殊规则和参考解为什么长这样。

## 第十八关「交叉」

导线贴边就相连，两条线在同一平面上没法直穿，交叉导线就是为这种情况准备的。这一关故意不给交叉导线，要的是**用逻辑门做出交叉的效果**：A、B 在左边上下对角，C、D 在右边上下对角，要求跑稳后 C = B、D = A——信号等于交换了位置。

参考解先搭出中间的 X = A XOR B，再用 C = A XOR X、D = B XOR X 得到结果，两条线谁都不用真的跨过谁；测试只看 4 种输入组合的稳态，任何等价电路都算过。名字里的「交叉」指的是效果，不是元件。

## 参考解取的状态

前十八关都有参考解（第十九关还没有）。`state` 里的取值就是导出时那一刻：

- 第十八关：A=0、B=0 跑稳之后（C=0、D=0，tick 60）
- 第八关：时钟低电平的一刻（Y=0，tick 39）
- 第十一关：A=0、Y=0（tick 104）
- 第十七关：J、K、C 全 0、Y=0（tick 255）
- 第十六关：T=0、Y=0（tick 219）
- 其余关卡：导出时的一刻

测试里把 `solution.cells` 和 `solution.state` 一起盖上、从保存的电路状态开始验证「参考解能过」。
