# 元件与信号规则

五种可放置元件和输入 / 输出端口的行为，以及中继器被侧面影响时的两条规则。

## 基本规则

- 导线传输无延迟、无衰减、无距离限制；导线贴边就相连。
- 中继器和非门延迟 1 tick 生效，其余元件在同一 tick 内传播到稳定（时间模型见[时间模型与仿真](simulation.md)）。

## 元件

| 元件 | 作用 |
| --- | --- |
| 导线 | 连成一片的导体，同一个网络一起带电 |
| 交叉导线 | 上下 / 左右两条独立通道，各走各的，互不导通 |
| 充能器 | 朝正面一个方向给相邻元件供能 |
| 中继器 | 读后方、延迟 1 tick 输出到正面；侧面被输出 1 的中继器顶住会锁存，被输出 1 的充能器顶住会断路 |
| 非门 | 读后方、延迟 1 tick 输出反相 |

## 输入 / 输出端口

输入 / 输出是端口，不算上面五种元件：

- 输入按玩家拨的 0 / 1 朝四个方向同时发信号；点地图上的输入元件（「交互」模式）或波形行首的字母都能切换。
- 输出收集四周朝它发出的信号，任意一个为 1 就是 1；自己不往外发信号。

## 中继器侧面锁存

只有中继器能锁。中继器被侧面相邻、正面顶过来并且正在输出 1 的中继器顶住时，它不再采样后方，输出原地保持，画面上三角形是实心的（空心表示照常采样）；侧面输出回到 0，才把后方的信号采样进来（照样延迟 1 tick）。前后方向是它自己读信号、输出的通路，不算侧面。

所以「中继器后面接 D、侧面接一个由 E 驱动的中继器」就是一个 D 锁存器：E=1 期间锁住，E=0 时 Y 跟着 D 走。锁存信号要先过侧面那个中继器，所以比原来用充能器的方案晚 1 tick 生效：E 和 D 同一拍变化时，那一拍 D 还可能被采进来，之后才锁住。

## 充能器侧面断路

充能器正面顶住中继器的侧面并且正在输出 1 时不再锁存，而是把输出掐断，相当于布尔减法 Y = D − E = D ∧ ¬E：E=1 时中继器不发信号；断路算进中继器自己的采样：这一拍按 0 记下，下一拍才输出，所以断开和侧面撤掉后的恢复都跟着中继器晚 1 tick。
